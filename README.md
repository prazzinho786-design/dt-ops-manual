# Direct Travel — Operations Manual

Team operations reference dashboard (processes, daily briefings, templates, VIP QC).

## Live link (after enabling GitHub Pages)

1. Repo **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main**, folder: **/ (root)**
4. Save

Then open:

**https://prazzinho786-design.github.io/dt-ops-manual/**

(Direct file: [Direct Travel Operations Manual.html](./Direct%20Travel%20Operations%20Manual.html))

## Update the team copy

1. Edit or replace `Direct Travel Operations Manual.html`
2. Commit & push to `main`
3. Everyone refreshes the Pages link

## Notes

- Briefings in the HTML seed are the source of truth for static hosting.
- Admin edits in the browser stay local to that device (no Claude shared storage on GitHub Pages).
- Claude Share may be blocked on some plans; GitHub Pages does not depend on Claude.
